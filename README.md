# SETU Creative Programming – Lab 4

## Project Description
This project was created as part of my Creative Programming Fundamentals 1 module at South East Technological University (SETU).

The project is an animated scene created using JavaScript and the p5.js library.

## What the Project Does
The program displays a colourful outdoor scene featuring:
- A house with windows and a door
- Two trees
- A sun and blue sky
- Green grass
- A moving cloud

## Technologies Used
- JavaScript
- p5.js
- HTML
- CSS

## What I Learned
Through this project, I practised:
- Using functions to organise code
- Drawing shapes using p5.js
- Working with colours and coordinates
- Creating simple animations
- Using variables to control movement
